# Code of Conduct

`oie-git-sync` is maintained by a sole developer and does not operate public
community spaces. The issue tracker, wiki, projects, and discussions are
disabled, and the project does not accept external contributions — see
[`CONTRIBUTING.md`](./CONTRIBUTING.md).

The only direct contact channel is private security reporting, described in
[`SECURITY.md`](./SECURITY.md). Any correspondence through that channel is
expected to be respectful and professional. Harassment, abuse, or the sharing
of others' private information will not be engaged with.

If you wish to take the project in a different direction, the licence permits
it: fork the repository and maintain your own copy under the
[Mozilla Public License 2.0](./LICENSE).
